# Brainμ Project Website

This website introduces Brainμ, a neuroscience foundation model for learning
across diverse neural modalities, species, and experimental paradigms.

It presents the model overview and demonstration, architecture, research team,
and citation information, with links to the project's GitHub repository and
released Hugging Face resources.

**Project code:** https://github.com/BAAI-Brain-Inspired-Group/Brainmu

**Hugging Face:** https://huggingface.co/baai-brain/brainmu-tokenizer
